# 📝 CEO 종합 보고서

📱 **보고서 요약 및 실행 계획**

현재 시스템은 **사용자(당신)**의 요청에 따라, 제공된 맥락(Context)을 분석하여 가장 적절한 실행 계획을 도출하는 역할을 수행합니다.

**[분석 결과]**

1.  **목표:** 제공된 정보를 바탕으로 가장 중요하고 실행 가능한 다음 단계를 결정하고 계획을 수립하는 것입니다.
2.  **핵심 정보:** 이 요청은 시스템이 현재 상태를 분석하고 다음 행동을 결정하도록 지시하는 메타-지시(Meta-Instruction)의 성격을 가집니다.
3.  **현재 상태:** 시스템은 사용자가 제공한 모든 맥락(이전 대화 기록, 설정 파일 등)을 참조하여 최적의 다음 행동을 결정해야 합니다.

**[실행 계획]**

현재 제공된 맥락만으로는 구체적인 외부 작업(예: 파일 생성, API 호출 등)을 수행할 수 없습니다. 따라서, **다음 행동을 결정하기 위해 구체적인 작업 지시가 필요합니다.**

**다음 단계:**

어떤 종류의 작업을 수행하기를 원하시는지 구체적으로 지시해 주십시오. 예를 들어, 다음과 같이 요청해 주시면 제가 그에 맞춰 계획을 수립하고 실행할 수 있습니다.

*   "최근에 작성한 메모를 요약해 줘."
*   "다음 주 계획을 세워 줘."
*   "이 정보를 바탕으로 보고서를 작성해 줘."
*   "특정 파일(예: 메모.txt)을 생성해 줘."
